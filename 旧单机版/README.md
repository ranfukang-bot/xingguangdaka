# 星光打卡 · 单文件桌面版

## 打开和发送

双击 **星光打卡.exe** 即可打开。发送给别人时，只需要发送这一个 EXE，不需要发送 index.html、BAT 或其他文件。

适用 Windows 10/11 64 位电脑。免安装，自带网页运行环境，不需要另外安装浏览器、Node.js 或 Python，也不需要联网。单文件启动时会自动解压运行组件，首次启动请等待数秒。

原来的「启动打卡系统.bat」也会优先打开 EXE。原始 index.html 保留，仍可单独用浏览器打开。

## 数据在哪里

- 桌面版数据保存在当前 Windows 用户的 `%LOCALAPPDATA%\StarPunch` 目录。
- 关闭、重新打开，或在同一台电脑、同一 Windows 用户下移动和重命名 EXE，数据仍会保留。
- EXE 内不包含员工和考勤记录。只发送 EXE 会在对方电脑上创建一套新的空数据。
- 换电脑时：在原电脑「管理 → 导出完整备份」，把 JSON 备份文件一起带走，在新电脑「管理 → 从备份恢复」。
- 原网页版本的数据属于原来的浏览器。如已使用旧版本，请先在原浏览器打开 index.html 导出备份，再导入桌面版。
- 建议每月发薪后导出完整备份。多台电脑不会自动同步。

## 保留的功能

员工管理、上班和任务完成打卡、考勤日历、工资结算、荣誉榜、管理员密码、员工打卡密码、考勤 CSV 导出、工资条打印、完整备份和恢复。

默认规则：11:00 前上班并在 16:00 前完成任务为全薪；迟到但按时完成任务为半薪；迟到且未按时完成为无薪；准时上班但未按时完成默认半薪。工作日、工资、截止时间和每月发薪日可在「管理」中调整。打卡使用电脑系统时间。

## 启动问题说明

旧 BAT 使用 Edge/Chrome 的 `--app=file:///...` 模式打开本地网页。在本机隔离测试中，Edge 未进入打卡页面，而是进入新标签页；直接加载同一 HTML 则正常。桌面版将页面和运行环境一起打包，直接加载内置页面。

若桌面版提示启动失败，可在 `%LOCALAPPDATA%\StarPunch\startup.log` 查看启动日志。
